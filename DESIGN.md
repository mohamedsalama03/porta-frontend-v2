# Porta interface system

The user's explicit design direction is the visual authority: calm, premium, Arabic operational SaaS. The Impeccable concept-seed was consulted; foreign decorative directions were declined because their shapes and motion would obstruct the specified table-heavy operations. The pinned brief takes precedence. Work is code-first within the authorized foundation scope; no persistent workflow preference is inferred.

## Visual language

Cairo with generous Arabic line-height, compact fixed-size hierarchy, tabular numerals, logical inline/block layout, warm near-white workspace and slightly differentiated sidebar. Teal marks primary actions and selection; semantic blue/amber/green/red are reserved for states. Intentional charcoal/green dark surfaces maintain contrast.

## Composition

Right sidebar and stable top bar frame server-rendered route content. Overview begins with an operational heading and compact metrics, followed by a modest chart and shipment status list, then recent shipments and active trips. Missing live metrics are unknown, never zero. Development preview fixtures are labelled and isolated from production.

## Primitives

Borders over shadows, 10–14px surface radii, 8px controls, consistent 4px spacing rhythm, readable 13–14px controls and 28px page headings. At narrow widths the sidebar becomes a modal drawer and table columns adapt; key identity and state stay visible.

## Interaction

Visible teal focus ring, 44px minimum touch targets where practical. Native dialog focus containment/escape/return for protected focus. Short opacity/translate entrances, immediate feedback, no delayed controls. All nonessential animation removed for reduced motion. Light/dark/system and comfortable/compact density persist only local preferences.

## Safety of product states

No fixture is an API response. No fake trend, count, notification, permission or successful mutation is presented as live. Contract-dependent operations show a calm unavailable state with an explanation and useful navigation. Production preview routes return 404.
